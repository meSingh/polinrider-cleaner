Reports on PolinRider are still coming in. Since September researchers have
seen its fake font file change its name again, found it starting at logon on
Windows under the name MicrosoftCLROptimization and traced its earliest known
code to npm packages published in May 2025. If you install npm packages or
open other people's projects in VS Code, check your computer first and your
GitHub account second.
