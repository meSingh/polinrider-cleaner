## New

- **A new name and a new home.** The project is now polinrider-scanner. The
  repository is [meSingh/polinrider-scanner](https://github.com/meSingh/polinrider-scanner)
  and the documentation is at [polinriderscanner.com](https://polinriderscanner.com).

## Changed

- **The program has not changed.** It is still `polinrider`, with the same
  options, output and exit codes. The layout of `ioc/` and the CI scan you
  copy into a repository are unchanged.
- Links to the site's old GitHub Pages address still work through redirect
  pages, and links to the old repository through GitHub's redirect.

## Breaking changes

**Every package is renamed to `polinrider-scanner`.**

- **Homebrew:** `brew upgrade` moves an existing `polinrider-cleaner` install
  to the new name.
- **Scoop:** run `scoop uninstall polinrider-cleaner`, then
  `scoop install polinrider-scanner`. The old name stays at 2.3.0.
- **Debian and Ubuntu:** installing the new `.deb` removes `polinrider-cleaner`.
- **winget:** the package is `meSingh.PolinRiderScanner`.

**Verifying a download.** Verify this and every later release with
`gh attestation verify <file> --repo meSingh/polinrider-scanner`. Releases
before 3.0.0 were built under the old name:
[Releases before 3.0.0](/docs/reference/verifying/#releases-before-300).
