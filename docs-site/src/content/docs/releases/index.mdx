One page per release: what it adds, what changes in what you will see, anything
that breaks, and downloads for your system. This is a list of releases, not of
commits. The full history is on
[GitHub](https://github.com/meSingh/polinrider-cleaner/commits/main).

Indicators are updated every week between releases. Those changes are in the
[indicator reviews](/polinrider-cleaner/indicator-reviews/), and a release
carries every indicator merged before it.
