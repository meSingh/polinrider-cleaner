Released 11 October 2026. The first release of the rewrite: one program,
`polinrider`, in place of the 1.x shell scripts.

## New

- **A guided flow.** Run `polinrider` with no arguments. It asks what to check,
  one question at a time, answered in words, and changes nothing until you type
  `yes`.
- **This computer, on macOS, Linux and Windows:** implant processes and
  connections, persistence, shell startup files, editor extensions, git hooks,
  build configs and fake fonts, all through one check.
- **`clean`** cuts a payload appended to a build config out in place and keeps
  the infected original in quarantine, instead of moving the whole file.
- **GitHub accounts and organizations:** every branch and tag of every
  repository is checked against GitHub's push record rather than commit dates,
  which the campaign backdates. Each repository can then be restored to its
  last clean pushed state, erased from history, cleaned with a new commit or
  archived, each shown as a dry run first.
- **Signed, attested downloads** for five systems, plus Homebrew and Scoop.

## Breaking changes

- **The 1.x shell scripts are gone:** `polinrider.sh`, the
  `github-account-recovery/` and `github-org-recovery/` folders and
  `machine-cleanup/`. Download the binary for your system instead of cloning
  the repository.
- `--state` and `--resume` are removed: 2.0 does not checkpoint a scan. Both
  are still recognised, and say so, rather than being reported as unknown.
- The exit codes are unchanged: `0` clean, `1` review, `2` compromised, `3`
  could not run.

The CI scanner, `ci/scan-workspace.sh`, is still shell and works as before.
