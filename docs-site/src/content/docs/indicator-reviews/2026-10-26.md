appeared between 2026-10-21 and 2026-10-26 that this review could find.

## Considered and not added

**`webrunc` (PyPI).** Named in episode 26 as a fetch-and-execute dropper found
by a researcher who first thought it was PolinRider. The speakers say it looked
nothing like PolinRider and describe no secondary payload or destination. The
only source is a spoken summary, which is enough to know it was published and
not enough to lift a name from, and nothing ties it to this campaign. Not added.

**Everything in the OpenSSF records that is not already in `ioc/`.** Two names,
`html-to-gutenberg` and `fetch-page-assets`, are hijacked legitimate packages
and are kept as comments with the poisoned versions, as decided on 2026-10-05
and 2026-10-21.

**The Brotli CVE material.** Vulnerability identifiers, not campaign indicators.

**Closed since they were first carried**, checked against `main` for this entry:

- **npm CLI persistence**: closed in 2.1.0. npm's own program files and the two
  `~/.npmrc` settings that run code are checked (ADR-0042).
- **Small-file hashes**: closed in 2.2.0 for the files the checks read whole:
  `.vscode/tasks.json`, font files and build configs are compared against
  `hashes.txt` at any size (ADR-0045). Still open for every other small file:
  the `print.cjs` dropper is not hashed where it usually sits.
- **Python-side coverage**: partly closed. Python `.pth` startup files are
  checked since 2.1.0 (ADR-0042). No entry has said what else this covers, so
  it is not carried as a gap of its own any more.

**Still open, unchanged:** `authorized_keys`, the blob-ID tier, the weak path
tier, the regex content tier, and the font-vector `.woff2` weights. The last
is narrower than earlier entries say: the local font check catches any fake
`.woff2` by its first bytes, as the CI scanner does; what is missing is
naming the weights, which needs the weak path or regex content tier.
