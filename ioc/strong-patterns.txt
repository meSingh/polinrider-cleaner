# Patterns over file contents, at the INFECTED tier: a match means the payload,
# as for strong.txt. For indicators a fixed string cannot say, because a part of
# them rotates. Extended regex, the subset src/pattern.rs supports. ADR-0052.
#
# Every pattern must contain a fixed part of at least three characters and no
# ^ or $: it is tried only near that fixed part, so a long payload line cannot
# make it slow. A pattern that breaks either rule stops the scan.

# node running a font file directly: the folderOpen task command of the fake
# font payload, whatever the weight and wherever the file sits. strong.txt has
# the 400 form as a fixed string; the 500 and 900 forms are live. The path must
# follow node as one argument, so a script that is merely handed a font name
# (node scripts/copy.js fa-solid-900.woff2) does not match.
# Source: OpenSourceMalware, "A Developer's Guide to Getting Rid of
# PolinRider", 2026-08-13, and "PolinRider is A/B Testing its Way Past Your
# Detections", September 2026; recorded in the 2026-09-14 and 2026-09-28
# indicator reviews.
node +[^ "']*fa-solid-[0-9]{3}\.woff2

# The var z campaign tag, behind the padding: the first statement of the hex
# blob and var NX table payloads, appended to the last line of a config or
# source file after 149 spaces (hex blob) or 266 tabs (var NX). The number
# rotates per build, as the global['!'] tag does. The padding is required, so
# a minified var z='-1' does not match. The brackets hold a space and a real
# tab character: in a bracket expression \t is a backslash and a t, here and
# in grep -E. A unit test fails if the tab becomes a space. Derived from the
# infected files at the paths OpenSourceMalware's PolinRider lists name (July
# and April 2026 lists, 265 of the 310 files the 2026-11-05 gap study
# fetched); no publication states the string. ADR-0058.
# Source: OpenSourceMalware, PolinRider dossier,
# https://github.com/OpenSourceMalware/PolinRider
[ 	]{64,}var z = '-[0-9]+(-[0-9]+)?';

# The global.i campaign tag, either quote style, any campaign number. The
# pinned A8 forms in strong.txt are two of its matches; A10 and A11 are the
# later builds. The number must be followed by - or a closing quote, so
# global.i = 'Alpha' does not match, and weak.txt keeps the looser
# global.i = 'A at review. The A10 and A11 values are derived from the
# infected files at the paths OpenSourceMalware's lists name (37 of the 310
# files of the 2026-11-05 gap study); the shape is SafeDep's.
# Source: OpenSourceMalware, PolinRider dossier,
# https://github.com/OpenSourceMalware/PolinRider; SafeDep, "PolinRider
# Switches to Ethereum C2 in 30+ Repositories", September 2026, whose hunt
# includes global\.i="A. ADR-0058.
global\.i ?= ?['"]A[0-9]{1,2}(-|'|")
