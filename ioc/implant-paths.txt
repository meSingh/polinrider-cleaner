# Second-stage implant install locations. Existence of any of these is a
# confirmed compromise, not a signal to weigh.
#
# The implant is a Node.js Single Executable Application: a native binary with
# the V8 engine and the JavaScript payload statically linked in. It does not
# need Node installed, and it sets its own process title to look like a system
# service. Endpoint tooling that expects either a native executable or an
# interpreted script tends to miss it.
#
# Sources: safedep.io MicrosoftSystem64 binary analysis; JFrog Security Research
# "Hugging Face as a malware CDN" (js-logger-pack), both April-May 2026.
#
# "~" is expanded to the user's home directory. Windows paths are checked by
# check-windows.ps1 only.

# --- working directories written by the implant
