# The fake-font payload with a non-font extension. The 2026-09-28 entry turned
# away fa-solid-900.woff2 because that is a genuine Font Awesome filename and
# this file is INFECTED tier. .llf is not: Font Awesome ships .woff2, .woff,
# .ttf, .eot and .svg, and nothing legitimate names an .llf after a font weight.
# Carried as a regex over the weight rather than one literal because that is
# what the source gives -- "they're keeping the front of the file name basically
# the same, so fa-solid- fill in a number [...] the one that I saw was 300, but
# instead of .woff2 it's a .llf" -- and because the whole point of the variant is
# that the number rotates. The .woff2 forms stay out, for the reason above.
# Source: OpenSourceMalware, The OpenSourceMalware Show #23, 2026-10-02
# (spoken transcript; over 120 versions reported live on GitHub on 2026-09-28).
(^|/)fa-solid-[0-9]{3}\.llf$
